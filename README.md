## 运行方式

```bash
# 安装依赖
pip install pygame

# 运行游戏
python3 main.py
```

## 游戏玩法

### 操作
- **点击卡牌**：选中要种植的植物
- **点击格子**：在空格子中种植选中的植物
- **点击阳光**：收集阳光

### 植物

| 植物 | 费用 | 功能 |
|------|------|------|
| 🌻 向日葵 | 50 | 产出阳光 |
| 🫛 豌豆射手 | 100 | 发射豌豆攻击僵尸 |
| 🥜 坚果墙 | 50 | 高血量防御 |
| ❄️ 寒冰射手 | 175 | 发射冰豌豆，减速僵尸 |
| 🍒 樱桃炸弹 | 150 | 3x3 范围爆炸 |
| 🥔 土豆地雷 | 25 | 延迟后爆炸 |
| 🌿 食人花 | 150 | 近战秒杀普通僵尸 |
| �.double 双发射手 | 200 | 连续发射2颗豌豆 |

### 僵尸

| 僵尸 | 特点 |
|------|------|
| 普通僵尸 | 普通进攻 |
| 路障僵尸 | 头顶路障，血量更高 |
| 铁桶僵尸 | 铁桶防护，极高血量 |
| 撑杆跳僵尸 | 速度更快，可跳过植物 |
| 橄榄球僵尸 | 速度快且攻击力强 |

## 项目结构

```
plants-vs-zombies/
├── main.py                 # 游戏入口
├── constants.py            # 显示常量
├── PRD.md                  # 设计文档
├── SPEC.md                 # 技术规格
├── resources/              # 资源文件
│   └── graphics/           # 植物/僵尸/卡牌图片
└── source/
    ├── constants.py        # 游戏数值常量
    ├── component/
    │   ├── map.py          # 5x9 格子地图
    │   ├── plant.py         # 植物基类
    │   ├── zombie.py        # 僵尸基类
    │   ├── bullet.py        # 子弹/粒子
    │   └── menubar.py       # 卡牌选择栏
    └── state/
        └── level.py         # 战斗关卡逻辑
```

## 技术栈

- **语言**: Python 3.12+
- **引擎**: Pygame 2.6.1
- **帧率**: 60 FPS
- **架构**: 状态机 + 组件模式
